BlueMapHUD is now called BlueMinimap. This release renames it and changes nothing else in how the map works. The owner chose the name on 2026-11-08.

This is an early 0.x release. It has passed bot tests on throwaway servers, but it hasn't been seen in a real game client yet.

## Upgrading from BlueMapHUD 0.1.0

- Swap `BlueMapHUD-0.1.0.jar` for `BlueMinimap-0.2.0.jar` with the server stopped. **Update HouseRules to 0.2.0 at the same time** if you use it: with an older HouseRules, BlueMinimap turns `/hud share` off and logs why, so shares can't skip chat circles.
- On first start, `plugins/BlueMapHUD/` is copied to `plugins/BlueMinimap/` if that doesn't exist yet. The old folder is left untouched as a backup. Nothing is ever overwritten.
- The pack is now `plugins/BlueMinimap/pack/blueminimap-pack.zip`, and its contents changed, so its SHA-1 changed. If you host it yourself, upload the new file. Players download it once.
- Players keep their HUD settings: they're stored under the same keys as before.
- **Deprecated, removed in the next release:** `/bmhud`, `/bluemaphud:map`, `/bluemaphud:hud` and the `bluemaphud.*` permissions. For permissions that are on by default, a "no" on either name wins, so a group you stopped from sharing stays stopped. Differences between the old and new names are logged once per player.
- Changed outright: the plugin, jar and folder are `BlueMinimap`, the admin command is `/blueminimap`, and the share event is `com.extantape.bluemapmini.api.CoordinateShareEvent` (same methods).
