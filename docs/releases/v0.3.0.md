BlueMinimap is now BlueMapMini (D194), so its name starts with BlueMap like the other BlueMap add-ons. Nothing else changed in how it works.

## Upgrading

- Swap `BlueMinimap-0.2.1.jar` for `BlueMapMini-0.3.0.jar` with the server stopped.
- On first start, `plugins/BlueMinimap/` is copied to `plugins/BlueMapMini/` if that doesn't exist yet. The old folder stays as it was.
- It still answers to the name BlueMinimap, and the share event keeps its class, so HouseRules keeps filtering `/hud share` without an update.
- `/blueminimap` and the `blueminimap.*` permissions still work in 0.3.x. A "no" under any old name wins for permissions that are on by default, so a group stopped from sharing stays stopped.
- If you host the pack yourself, upload the rebuilt `plugins/BlueMapMini/pack/bluemapmini-pack.zip`.

## Tested

Unit tests pass, including a children's group whose `blueminimap.share.receive` was turned off staying off. The carry-over, the old name and HouseRules' share filter were checked on a throwaway server.
