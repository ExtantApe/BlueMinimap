A new name (D194): BlueMapMini starts with BlueMap, like the other BlueMap add-ons. How it works hasn't changed. As the owner asked (D196), it keeps no old names: no old commands, permissions or folder copy.

## Installing over the previous version

With the server stopped:
1. Rename its plugin folder to `plugins/BlueMapMini`.
2. In LuckPerms, move every node of the plugin's old permissions to the matching `bluemapmini.*` node, in every group and for every player. Most are on by default, so a group that had sharing turned off must have `bluemapmini.share.send` (and `.share.receive`) set to false, or it can share again.
3. Update HouseRules to 0.5.0 at the same time. Until it is, BlueMapMini keeps `/hud share` off, so shares can't skip chat circles.
4. If you host the pack yourself, upload the rebuilt `plugins/BlueMapMini/pack/bluemapmini-pack.zip`.

Players' HUD settings start fresh once, and clients download the pack once more, because both were stored under the old name.

## Tested

Unit tests pass, including sharing staying off with a HouseRules older than 0.5.0.
